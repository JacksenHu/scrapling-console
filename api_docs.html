快速开始（Python）

一个完整链路：注册 → 拿 API Key → 抓取

# 1. 注册并登录（免费，注册即送额度） import requests BASE = "https://YOUR-SERVER:8080" r = requests.post(f"{BASE}/api/auth/register", json={"email": "you@example.com", "password": "yourpass123"}) token = r.json()["token"] # 会话 token H = {"X-Session-Token": token} # 2. 创建 API Key（REST / MCP 都用它鉴权） r = requests.post(f"{BASE}/api/me/apikeys", json={"name": "我的程序"}, headers=H) API_KEY = r.json()["key"] # sk- 开头，只显示一次 A = {"X-Api-Key": API_KEY, "Content-Type": "application/json"} # 3. 快捷抓取一个网页（普通/反爬/截图/批量任意选） r = requests.post(f"{BASE}/api/mcp/quick", json={"mode": "stealthy", "url": "https://example.com"}, headers=A) print(r.json()["result"]["text"][:500]) # 网页内容 # 4. 用代理池的 IP 访问注册页（防风控） r = requests.post(f"{BASE}/api/proxy/visit", json={"url": "https://example.com/register", "mode": "browser", "retries": 2}, headers=A) print(r.json()["exit_ip"]) # 出口 IP（保证不是你的服务器 IP）

鉴权与规则

X-Api-Key: sk-...REST 接口鉴权头（除登录/注册/公开接口外都必需），每次调用按接口扣额度
Authorization: Bearer sk-...MCP Server 鉴权（Streamable HTTP）
X-Session-Token: ...网页登录会话 token（/api/auth/login 返回），仅用于用户相关接口
X-Auth: ...平台主 PIN（主人通道专用）
错误返回 HTTP 状态码 + JSON {"detail": "原因"}；额度不足返回 402；未授权 401；无权限 403。

② 快捷抓取（核心）
POST/api/mcp/quick一键抓取：等同控制台「快捷任务」。普通抓 / 反爬抓 / 提取元素 / 截图 / 批量，自动编排参数
参数类型说明

url必填string目标网址（bulk 模式用 urls 字段）

use_proxy必填bool是否轮换代理池（防风控）

# 响应示例 {"ok": true, "mode": "stealthy", "steps": [{"tool": "stealthy_fetch", "args": {...}}], "result": {"type": "text", "text": "页面内容..."}, "status": "done"}

⑥ 用代理访问网址（注册防风控核心）
POST/api/proxy/visit用代理池的 IP 打开一个网址（注册页/目标页），自动防 IP 泄漏
参数类型说明
url必填string目标网址，如 https://example.com/register
mode必填stringplain=纯HTTP请求(最快) | browser=隐身浏览器渲染(推荐注册页) | screenshot=浏览器截图，默认 plain

timeout必填int超时秒数 5-120，默认 30
# 用代理打开注册页（浏览器隐身模式，自动换 IP 重试） curl -X POST https://YOUR-SERVER:8080/api/proxy/visit -H "X-Api-Key: sk-你的APIKey" -H "Content-Type: application/json" -d '{"url":"https://example.com/register","mode":"browser","retries":2}' # 指定一个代理直连 curl -X POST https://YOUR-SERVER:8080/api/proxy/visit -H "X-Api-Key: sk-你的APIKey" -H "Content-Type: application/json" -d '{"url":"https://example.com","mode":"plain","proxy":"1.2.3.4:8080"}'
# 响应示例 {"ok": true, "mode": "browser", "proxy": "http://1.2.3.4:8080", "exit_ip": "6.7.8.9", "ms": 8120, "attempts": 1, "result": {"type": "text", "text": "页面内容..."}}
exit_ip 保证 ≠ 服务器 IP：检测到透明代理（出口=服务器 IP）会自动丢弃并换下一个，绝不裸奔。screenshot 模式 result.type=image。访问成功会自动回写存活代理池，越用越准。

⑧ 持久会话（指纹 / CDP / 代理）

POST/api/tasks创建爬虫任务（容器隔离执行，可暂停/恢复/断点续爬）
参数类型说明
type必填stringcrawl=全站爬取(默认) | single=单页提取 | sitemap=站点地图 | xml=RSS | csv=CSV Feed | shopify=Shopify 商店产品
name必填string任务名
start_urls必填string起始网址，逗号或换行分隔（shopify 可用 target_website）
target_website必填string仅 shopify：商店域名
fields必填string提取字段，每行「字段名:选择器」如「标题:h1 价格:.price」
allowed_domains必填string允许域名（逗号分隔），不填自动取起始网址域名
crawl_rules必填object/string爬取规则 allow 列表
concurrency必填int并发数，默认 4
download_delay必填float请求间隔秒，默认 0
autothrottle必填bool自动限速
robots_txt_obey必填bool遵守 robots.txt
adaptive必填bool自适应反爬
proxy_rotation必填bool轮换代理池
export_format必填stringjsonl(默认)/csv/json/xml
# 全站爬取（自动跟随站内链接） curl -X POST https://YOUR-SERVER:8080/api/tasks -H "X-Api-Key: sk-你的APIKey" -H "Content-Type: application/json" -d '{"type":"crawl","name":"抓我网站","start_urls":"https://example.com","fields":"标题:h1\n价格:.price","proxy_rotation":true,"export_format":"csv"}' # 抓 Shopify 商店产品 curl -X POST https://YOUR-SERVER:8080/api/tasks -H "X-Api-Key: sk-你的APIKey" -H "Content-Type: application/json" -d '{"type":"shopify","target_website":"mystore.com"}'
# 响应示例 {"ok": true, "task": {"id": "t260925143000abcd", "name": "...", "status": "created", ...}, "script_preview": "spider.py 前 2000 字符"}
