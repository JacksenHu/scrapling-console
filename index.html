13 个 MCP 工具逐个教学按使用频率分三组：日常抓取 / 高防网站 / 会话三件套

A 组 · 日常抓取（先用这几个就对了）覆盖 90% 的抓取需求
fetch 浏览器抓取 最常用 ⭐
大白话：偷偷开一个真浏览器，把网页打开、渲染完，再把内容拿回来。
用它干嘛：抓普通新闻、论坛、商品页；网页内容靠 JS 动态加载、直接请求拿不到时，必须用它。
1填 URL（必填）
2想只要正文 → 勾 main_content_only（去广告导航）
3想取特定内容 → 在 css_selector 填选择器（如 .price）
4点「调用工具」
网站有 Cloudflare 盾牌/验证码时它可能 403，这时换 B 组的 stealthy_fetch。
make_request HTTP 请求 最快最省
大白话：不开浏览器，直接用程序"按门铃"拿数据。比浏览器快几十倍。
用它干嘛：抓 API 接口（返回 JSON）、提交表单、下载文件；页面不需要 JS 渲染时的首选。
1填 URL（必填）
2选 method：GET 拿数据 / POST 提交
3POST 时在 json 或 data 填要提交的内容
4点「调用工具」
只适合"普通"网站；遇到反爬就换 stealthy_fetch。接口返回 JSON 时结果会直接显示。
bulk_get 批量 HTTP 一批抓多个
大白话：一次把好几个接口/页面一起抓回来，不用一个个点。
用它干嘛：同时抓一批商品价格、多个新闻链接、批量检查链接是否有效。
1在 urls 填数组（JSON 格式：["https://a.com","https://b.com"]）
2点「调用工具」，结果会按顺序返回
urls 要用 JSON 数组格式；几十个一起抓注意别太大，分批更好。
bulk_fetch 浏览器批量 一批抓多个
大白话：开一个浏览器，同时打开多个网页并抓回内容。
用它干嘛：批量抓需要渲染的页面（商品详情、文章列表）；比一个个 fetch 快很多。
1在 urls 填 JSON 数组
2想只要正文勾 main_content_only
3点「调用工具」
数量多会占内存（服务器只有 1.7G），建议一次别超过 10 个。
B 组 · 高防网站（网站有盾牌就靠它）Cloudflare、人机验证、强反爬的唯一解
stealthy_fetch 隐身衣抓取 高防专用
大白话：披上"隐身衣"（模拟真人浏览器指纹+行为），骗过网站的机器人检测。
用它干嘛：抓有 Cloudflare 盾牌、验证码、403 拦截、提示"检测到异常流量"的网站。高防护网站只有它能过。
1填 URL（必填）
2遇到 Cloudflare → 勾 solve_cloudflare
3点「调用工具」
比 fetch 慢一点（要伪装得更细致）；被限流可以勾「轮换代理池」。
bulk_stealthy_fetch 隐身批量 高防批量
大白话：穿隐身衣一次抓多个高防页面。
用它干嘛：批量抓有防护的商品/文章列表。
1urls 填 JSON 数组
2需要时勾 solve_cloudflare
3点「调用工具」
高防网站批量更容易被限流，建议配合代理 + 分批。
C 组 · 会话三件套（要登录、要连续翻页、要截图）浏览器一直开着等你用
open_session 开浏览器房间 第一步
大白话：在服务器后台开一个"一直开着的浏览器"，给你一把钥匙（session_id）。
用它干嘛：需要保持登录状态、连续抓很多页、要截图前的第一步。
1选 session_type：dynamic（普通）/ stealthy（防爬）
2headless 默认 True（不弹窗，省资源）
3点「调用工具」→ 记下返回的 session_id
开完一定要用 close_session 关掉，否则浏览器一直占内存。
session_fetch 用房间抓页面 第二步
大白话：用已经开好的浏览器去抓网页（带着登录状态、不用重新开）。
用它干嘛：登录后才能看的页面、连续翻页抓列表、需要保持会话的多步操作。
1填 url（必填）
2填 session_id（开房间时拿到的钥匙，必填）
3点「调用工具」
session_id 填错会报错；去「浏览器会话」面板能看到当前所有房间的 id。
session_make_request 用房间调接口 第二步
大白话：用已开的 HTTP 会话发请求，保留 cookies（比如登录 token）。
用它干嘛：登录后调 API、带 token 连续请求接口。
1先 open_request_session 开 HTTP 会话
2填 url + session_id（必填）
3点「调用工具」
HTTP 会话比浏览器会话更省资源；只调接口用这个就够了。
open_request_session 开 HTTP 会话 第一步
大白话：开一个"没有浏览器、纯网络"的会话，专门给接口用，快且省内存。
用它干嘛：调 API 前先开它，之后 session_make_request 就能带着登录状态发请求。
1impersonate 默认 chrome（伪装成 Chrome 浏览器）
2点「调用工具」→ 记下 session_id
它不带浏览器，不能截图、不能渲染页面。
screenshot 网页截图 要图就选它
大白话：给网页拍张照片（支持整页长截图）。
用它干嘛：保存网页证据、预览页面长相、给电商商品页留档。
1先 open_session 开浏览器（必填前提）
2填 url + session_id（必填）
3full_page 勾 True = 截整页长图
4点「调用工具」，图片直接显示在结果里
别忘了关会话。快捷任务的「网页截图」模式已经帮你自动开→截→关，小白直接用那个。
list_sessions 看房间列表 查看
大白话：列出所有开着的"房间"（会话）和它们的配置。
用它干嘛：忘记 session_id 了？忘了关会话？来这里看。
1直接点「调用工具」（无需参数）
本页「MCP 工具台」底部有「浏览器会话」面板，就是它，还能一键关闭。
close_session 关房间 用完必做
大白话：把开着的浏览器关掉，释放内存。
用它干嘛：每次用完会话后的收尾动作；服务器内存小，不关会卡。
1填 session_id（必填，要关哪个房间）
2点「调用工具」
关掉的会话不能再用于 session_fetch；用错了 id 会报错，重新开一个即可。

参数大白话什么时候填

开关大白话什么时候开

常见问题 FAQ抓不到东西先看这里

Q1：抓回来的内容是空的 / 乱码？

① 试试把 extraction_type 换成 html 看看原始结构；② 用 css_selector 精确定位；③ 网页内容是 JS 动态加载的 → 用 fetch（浏览器渲染）而不是 make_request；④ 偶尔遇到压缩编码问题，换 fetch 再试即可。

Q2：网站返回 403 / 验证码 / "检测到异常流量"？

这是反爬拦截。改用 stealthy_fetch（隐身衣），必要时勾 solve_cloudflare + 开「轮换代理池」。还不行就放慢频率（加延迟/自动限速）。

Q3：代理池为什么慢？存活率为什么低？

免费代理很多是"僵尸"，不稳定。用「代理池」页的存活检测先筛一遍，或者用高匿代理。任务开着代理轮换时会明显变慢，这是正常的。

Q4：爬虫任务点了暂停没反应？

任务太快跑完了（秒级任务）来不及暂停；暂停对大网站（分钟级）效果明显。暂停后状态变「已暂停」，点恢复从断点继续，已抓的不重复。

Q5：服务器会不会卡死？内存不够怎么办？

服务器只有 1.7G 内存。建议：同一时间只跑一个爬虫任务；并发数别超 4；浏览器会话用完就 close_session；别同时开太多 dynamic 会话。

Q6：我要登录才能看的内容怎么抓？

用会话三件套：open_session 开房间 → （在浏览器里登录一次）→ session_fetch 带登录状态抓 → close_session。或先手动拿到登录后的 cookie，填到工具的 cookies 参数里。

Q7：MCP 工具和爬虫任务有什么区别？

MCP 工具 = 即时工具，抓一次给你一次结果，适合临时抓取、验证。爬虫任务 = 后台程序，适合批量、定时、全站抓取，结果落盘可导出。小任务用工具，大工程用任务。

Q8：怎么确认我的选择器写对了？

先到「MCP 工具台」用 fetch + css_selector 试抓一页，结果里有内容就说明选择器对，再建爬虫任务批量跑。

快速开始（Python）

一个完整链路：注册 → 拿 API Key → 抓取

# 1. 注册并登录（免费，注册即送额度） import requests BASE = "https://YOUR-SERVER:8080" r = requests.post(f"{BASE}/api/auth/register", json={"email": "you@example.com", "password": "yourpass123"}) token = r.json()["token"] # 会话 token H = {"X-Session-Token": token} # 2. 创建 API Key（REST / MCP 都用它鉴权） r = requests.post(f"{BASE}/api/me/apikeys", json={"name": "我的程序"}, headers=H) API_KEY = r.json()["key"] # sk- 开头，只显示一次 A = {"X-Api-Key": API_KEY, "Content-Type": "application/json"} # 3. 快捷抓取一个网页（普通/反爬/截图/批量任意选） r = requests.post(f"{BASE}/api/mcp/quick", json={"mode": "stealthy", "url": "https://example.com"}, headers=A) print(r.json()["result"]["text"][:500]) # 网页内容 # 4. 用代理池的 IP 访问注册页（防风控） r = requests.post(f"{BASE}/api/proxy/visit", json={"url": "https://example.com/register", "mode": "browser", "retries": 2}, headers=A) print(r.json()["exit_ip"]) # 出口 IP（保证不是你的服务器 IP）

鉴权与规则

X-Api-Key: sk-...REST 接口鉴权头（除登录/注册/公开接口外都必需），每次调用按接口扣额度
Authorization: Bearer sk-...MCP Server 鉴权（Streamable HTTP）
X-Session-Token: ...网页登录会话 token（/api/auth/login 返回），仅用于用户相关接口
X-Auth: ...平台主 PIN（主人通道专用）
错误返回 HTTP 状态码 + JSON {"detail": "原因"}；额度不足返回 402；未授权 401；无权限 403。

⑦ 住宅节点（第三方应用集成通道）

参数类型说明
